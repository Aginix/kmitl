=======================
Procurement Plan Report
=======================

Report and export layer for the Procurement Plan (แผนจัดซื้อจัดจ้าง) module.

This module adds printable documents and export outputs for procurement plans
on top of the base ``procurement_plan`` module, without modifying the core plan
model or its workflow.

Configuration
=============

No configuration required. Reports become available on the Procurement Plan
records and menus once the module is installed.
