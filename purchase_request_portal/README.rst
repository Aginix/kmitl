This module provides portal access for purchase requests, allowing users to view their purchase requests
through the Odoo portal with an embedded HTML report display using iframe.

**Table of contents**

.. contents::
   :local:

Features
========

* Portal access for purchase requests
* HTML report display using iframe
* PDF download capability
* Access token-based security
* List view of all accessible purchase requests
* Detailed view with embedded report
* Automatic iframe height adjustment based on content

Usage
=====

Portal Access
-------------

1. Users can access their purchase requests from the portal at ``/my/purchase_requests``
2. Click on a specific purchase request to view details
3. The purchase request report is displayed in an iframe with HTML rendering
4. Download PDF version using the "Download PDF" button

Technical Details
-----------------

* The module extends ``purchase.request`` with ``portal.mixin``
* Provides ``get_portal_url()`` method for URL generation with access tokens
* Controller routes:

  * ``/my/purchase_requests`` - List all purchase requests
  * ``/my/purchase_request/<id>`` - View specific purchase request
  * ``/my/purchase_request/<id>/html`` - Render HTML report
  * ``/my/purchase_request/<id>/pdf`` - Download PDF report

* Uses the existing ``purchase_request.report_purchase_request`` report template
* JavaScript automatically handles iframe loading and height adjustment
