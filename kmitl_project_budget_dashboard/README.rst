==============================
KMITL Project Budget Dashboard
==============================

Registers the **โครงการ/กิจกรรม** Pool Tag (``kmitl_project_analytic_id``) with the ตรวจสอบงบประมาณ report,
so each budget code lists the โครงการ/กิจกรรม that hold money on it. Clicking an item opens its ``kmitl.project`` record.

Bridge between ``kmitl_project`` and ``budget_dashboard_pool_tag``; installs
automatically when both are present.
