Lets the finance office keep a table of rules that choose the payment
subject (เรื่องที่จ่าย) of a disbursement request for the auditor.

A rule matches on payee type, source, department, fund, activity and
payment type; an empty criterion matches anything and the first matching
rule by sequence wins. The subject is filled in only while the request
has none and no voucher exists, so the auditor can always change it.
