This module provides Budget Appropriation management functionality for KMITL.

**Features:**

* Create budget appropriations as drafts before posting budget moves
* Review and approval workflow for appropriations
* Automatic conversion to budget moves when posted
* Full integration with KMITL's 4D analytic framework
* Multi-company support with proper security rules

Usage
=====

Budget Appropriation workflow:

1. **Draft Stage**: Create appropriation with multiple lines
2. **Review Stage**: Submit for approval
3. **Posted Stage**: Creates budget moves automatically

The module integrates seamlessly with the existing budget system while providing
a preliminary planning stage without affecting actual budget accounting.
