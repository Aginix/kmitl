When accounting creates the vendor bills of a disbursement request, the
request's memo number (เลขที่หนังสือ) is written into each bill's notes
(``narration``), which also print as หมายเหตุ on the voucher.

The memo number is the one e-Saraban issued, or the one typed on a direct
claim. It is copied once, when the bills are created; a request without a
memo number leaves the notes empty.
