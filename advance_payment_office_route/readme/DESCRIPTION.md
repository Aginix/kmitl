Office approval route (flow สำนักงาน) for advance payments: requests from the
operating units chosen in Settings → สัญญายืมเงิน → เส้นทางการอนุมัติ skip the
supervisor's endorsement — แบบร่าง → รอตรวจสอบคำขอ → รอผู้อำนวยการพิจารณา →
รอผู้มีอำนาจอนุมัติ → รอโอนเงิน → ค้างชำระ → ปิดสัญญา — and the director's
signature fills the contract's เสนอ block. The route is fixed when the request
is submitted (advance_payment ADR-0027).
