=================================
Procurement Plan Budget Dashboard
=================================

Registers the **แผนจัดซื้อจัดจ้าง** Pool Tag (``procurement_plan_analytic_id``) with the ตรวจสอบงบประมาณ report,
so each budget code lists the แผนจัดซื้อจัดจ้าง that hold money on it. Clicking an item opens its ``procurement.plan`` record.

Bridge between ``procurement_plan_budget`` and ``budget_dashboard_pool_tag``; installs
automatically when both are present.
