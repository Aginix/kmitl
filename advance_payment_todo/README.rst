Marks the advance-payment step To-Dos (เห็นชอบ, ตรวจสอบ, พิจารณา, อนุมัติ,
สร้างใบสำคัญจ่าย) as *execution* Todos in the unified Todo inbox, so they
clear only when the step is taken on the loan — never by "Mark as Read".
Installs automatically with ``advance_payment`` and
``mail_activity_todo``.
