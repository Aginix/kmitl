Picks the budget code of a ถัวจ่าย row (รายการจองงบประมาณ) from the budget-code
tree (`ztree_select`) instead of a flat dropdown. Only the codes the row may take
(ticked ถัวจ่ายได้, funded at the reservation's dimensions, not on a row yet) are
selectable; their parent codes show greyed out to keep the tree readable.
