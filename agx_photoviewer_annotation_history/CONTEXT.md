# Photo Viewer — Annotation History

Lets whoever checks an attachment see how its Annotation layer got to where it is: who
added, changed or removed which marks, and when, drawn on the page.

## Language

**Change**: Everything one user added, changed or removed on a file in one visit of the
photo viewer — the same visit the Session note summarises. Listed in the History with
its author and time. _Avoid_: revision, version, edit

**History**: The Changes of one attachment, newest first, in a side panel of the viewer.
Opening a Change shows the layer as it left it, read-only. _Avoid_: log, audit trail,
timeline

**Event**: One addition, change or removal of one Annotation; the record a Change is
made of. Kept once the Annotation is removed. _Avoid_: action, operation
