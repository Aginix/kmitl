Purchase request approval document (พจ.1) for KMITL procurement. Extends
the purchase request with an approval workflow (draft → to approve →
approved), requesting department and fiscal year tracking, Sarabun
document integration, and a customer portal.

Includes the material withdrawal flow, dedicated reports (purchase
request approval and material withdrawal), and mail thread tracking for
the full audit trail.

Usage
=====

1. Open **Purchase Request Approval** from the procurement menu.
2. Create a request, set the requesting department and fiscal year, and
   add lines.
3. Submit the request for approval and let it move through the approval
   workflow.
4. Use the search filters (for example **Under Central**) to narrow the
   list by requesting department.
5. Print the purchase request approval or material withdrawal reports as
   needed.
