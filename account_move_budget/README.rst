This module provides seamless integration between Odoo's standard account moves (journal entries)
and KMITL's comprehensive budget system, enabling automatic budget consumption tracking and validation.

Features
========

Budget Integration
------------------

* **Automatic Budget Detection**: Automatically identifies journal entries that require budget commitment
* **Budget Availability Checking**: Real-time budget availability validation before posting
* **Budget Commitment Workflow**: Complete budget reservation and consumption lifecycle
* **4D Analytic Integration**: Full integration with KMITL's 4-dimensional financial tracking

Budget Workflow
---------------

1. **Detection**: System automatically detects expense journal entries requiring budget
2. **Validation**: Check budget availability using analytic dimensions
3. **Reservation**: Reserve budget commitment before posting
4. **Consumption**: Automatically consume budget when journal entry is posted
5. **Cancellation**: Cancel budget commitments when journal entries are cancelled

User Interface
--------------

* **Budget Status Indicators**: Visual status badges showing budget state
* **Action Buttons**: "Check Budget" and "Reserve Budget" buttons
* **Budget Tab**: Dedicated tab for budget account and analytic dimension configuration
* **List Filters**: Filter journal entries by budget status
* **Integration**: Seamless integration with existing account move workflows

Technical Architecture
======================

This module leverages KMITL's proven `budget.commitment.mixin` architecture, ensuring:

* **Consistency**: Same patterns as other budget-integrated modules
* **Reliability**: Uses tested budget framework components
* **Maintainability**: Minimal code duplication
* **Performance**: Optimized budget availability checking

Key Components
--------------

* **budget.commitment.mixin**: Provides core budget integration functionality
* **analytic.distribution.mixin**: Enables 4D analytic dimension support
* **Budget Controller**: Handles complex budget availability calculations
* **Budget Moves**: Automatic creation of budget consumption entries

Usage
=====

For Expense Journal Entries
---------------------------

1. Create a journal entry with expense account lines
2. The system automatically detects budget requirement
3. Configure budget account and analytic dimensions in the Budget tab
4. Click "Check Budget" to verify availability
5. Click "Reserve Budget" to create budget commitment
6. Post the journal entry - budget is automatically consumed

For Vendor Bills
----------------

1. Create or receive a vendor bill
2. System detects if budget commitment is required
3. Set budget account and analytic dimensions
4. Reserve budget before confirming the bill
5. Budget is consumed when the bill is posted

Configuration
=============

Budget Accounts
---------------

Configure budget accounts in **Budgeting > Configuration > Budget Accounts**:

* Set `Budgetable = True` for accounts requiring budget control
* Set `Budget Type = Expense` for expense accounts
* Configure account codes matching your chart of accounts

Analytic Dimensions
-------------------

Configure the 4 required analytic dimensions:

* **Activities** (กิจกรรม): Government programs and activities
* **Departments** (หน่วยงาน): Organizational units  
* **Funds** (กองทุน): Fund sources and classifications
* **Sources** (แหล่งเงิน): Money source types

Access Rights
-------------

* **Budget Users**: Can view budget information and check availability
* **Budget Managers**: Can create and manage budget commitments
* **Accounting Users**: Standard account move operations with budget integration

Known Issues / Roadmap
======================

* Currently focuses on expense transactions; could be extended to other transaction types
* Budget validation is enforced at posting time; could add draft-time warnings
* Integration with purchase workflows could be enhanced
