======================
Budget Floating Window
======================

Glue between ``budget`` and ``agx_floating_window``: the "สถานะงบ" button of a
budget document (purchase request, approval request, …) opens the budget
dashboard (ตรวจสอบงบประมาณ) in a draggable, non-modal floating window instead
of a modal dialog, so the form stays editable beside it and several checks
can be open at once.

Installed automatically when both modules are installed.
