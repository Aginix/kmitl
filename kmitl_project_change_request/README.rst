=================================
KMITL Project — Change Requests
=================================

Projects take Change requests (``agx_change_request``): whoever checks a
project details what to fix or explain as Change requests, on the project or
pinned on its files.

* Assignees are notified with an activity, and every step and reply is posted
  on the project's chatter.
* Requests never hold up the project: no step waits for them.
* A project officer (Officer/Manager) may close a request on its author's
  behalf.
