Adds the **หนังสือสารบรรณ** kind to a loan's เอกสารอ้างอิงเพิ่มเติม
(``advance_payment_related_document``). The borrower types the letter's
number (and, since the running number restarts every fiscal year, its
ลงวันที่ when the number alone is ambiguous); the letter is looked up under
sudo, so the borrower need not be one of its recipients. Installs
automatically with both modules.
