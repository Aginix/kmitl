Seeds the **หนังสือสารบรรณ** kind of เอกสารอ้างอิงเพิ่มเติม
(`advance_payment_related_document`): the letter's number, เรื่อง and ลงวันที่ —
the register number restarts every fiscal year, so ลงวันที่ tells repeated
numbers apart. The administrators own the kind from then on (ชนิดเอกสารอ้างอิง).
Installs automatically with both modules.
