This module adds a portal section where applicants can view the status of their own recruitment applications.

**Table of contents**

.. contents::
   :local:

Overview
========

Portal users (applicants) can track their job applications through the ``/my/applications`` portal page. Applications are matched to the logged-in user by partner record or email address.

Features
========

Application List
----------------

* View all own recruitment applications at ``/my/applications``
* Sortable by date, job position, or stage
* Paginated list with status badges (In Progress, Hired, Not Progressed)

Application Detail
------------------

* Stage progression bar showing completed, current, and future stages
* Application details: job position, department, dates, status
* Sidebar with key facts (applied date, hire date, department)

Security
--------

* Portal users can only view their own applications
* Dual matching: by ``partner_id`` or ``email_from`` (case-insensitive)
* Archived/refused applications remain visible with appropriate status
* Read-only access enforced at both ORM (ir.rule) and controller level

Configuration
=============

No configuration is required. Install the module and portal users with matching email addresses or partner records will see their applications.

Access Rights
-------------

The module grants portal users read-only access to:

* ``hr.applicant`` (filtered by record rule to own records only)
* ``hr.recruitment.stage``
* ``hr.job``
* ``hr.department``

Usage
=====

For Applicants
--------------

1. Log in to the portal
2. Navigate to **My Account** (``/my``)
3. Click **My Applications**
4. View the list of applications and click any row for details

For HR Staff
------------

No changes to the backend workflow. Applications managed in the standard recruitment pipeline are automatically visible to the applicant in the portal.
