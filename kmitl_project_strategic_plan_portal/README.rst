=====================================
KMITL Project — Strategic Plan Portal
=====================================

Adds แผนบริหารสถาบัน, ข้อตกลงการปฏิบัติงาน and แผนกลยุทธ์/แผนบริหารส่วนงาน to
the แผนยุทธศาสตร์ list on the project portal page.

Bridge between ``kmitl_project_strategic_plan`` and ``kmitl_project_portal``;
installs automatically when both are present.
