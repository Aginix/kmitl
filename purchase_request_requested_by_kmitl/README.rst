====================================
Purchase Request Requested By KMITL
====================================

Restrict editing of **Requested by** (``requested_by``) on the พ.1
(``purchase.request``) form to members of
**Purchase Request User : All Documents**
(``purchase_request_kmitl.group_purchase_request_user_all``).

Other users see the field as read-only; it still defaults to the current
user on create. The restriction is UI-only.
