Adds an **Under Central** predefined filter to the พจ.1
(``purchase.request.approval``) search view, restricting records to
requesting departments whose code belongs to the central administration
(ส่วนกลาง).

The list of central-administration department codes is kept in this
module, so the core ``purchase_request_approval`` module stays
untouched.

**Table of contents**

.. contents::
   :local:

Usage
=====

1. Open **Purchase Request Approval** (พจ.1) list view.
2. In the Filters dropdown, select **Under Central**.
3. The list now shows only requests whose requesting department is under
   the central administration.
