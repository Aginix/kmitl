Simple office order (คำสั่ง) management module. Each order stores a reference number,
title, date, and description, with file attachments managed through Odoo's standard
attachment system.

Includes mail thread integration for internal communication and tracking.

Usage
=====

1. Go to **Office Order** from the main menu.
2. Create a new order with a reference number, title, and date.
3. Attach supporting documents using the attachments button.
