# มีอะไรใหม่ — 17 ตุลาคม 2569

## 📨 สารบรรณ

### ปรับปรุง — ลำดับที่มีผู้ดำเนินการหลายคน ใครทำก่อนหนังสือก็ไปต่อได้

- ถ้าในลำดับเดียวกันมีผู้ดำเนินการหลายคน (เช่น **ผ่านเรื่อง/กลั่นกรอง** 2 คน)
  เมื่อคนใดคนหนึ่งดำเนินการแล้ว หนังสือจะไปลำดับถัดไปทันที ไม่ต้องรอให้ครบทุกคน
- คนอื่นในลำดับนั้นที่ยังไม่ได้ดำเนินการจะถูกข้าม และรายการใน To-do จะหายไป
- ถ้ามีคนใดคนหนึ่ง **ปฏิเสธ** หนังสือทั้งฉบับยังถูกปฏิเสธเหมือนเดิม
- ขั้น **รับทราบ** และ **สำเนาเรียน** ไม่เปลี่ยน

### แก้ไข — ตีกลับให้ผู้ส่งเริ่มใหม่ เส้นทางเดิมไม่หาย

- เมื่อหนังสือถูก **ตีกลับ** แบบ **กลับผู้ส่ง + เริ่มใหม่** เส้นทางที่ผู้ส่งแก้ไว้
  ขั้นที่เพิ่มจากการเกษียนสั่งการ และผู้ที่ได้รับมอบหมายแทนจะยังอยู่ครบ
  ไม่ต้องสร้างเส้นทางใหม่ทั้งหมด

### ปรับปรุง — To-do บอกชื่อเรื่องและผู้ส่ง

- รายการหนังสือใน To-do แสดง **เรื่อง** ของหนังสือเป็นบรรทัดหลัก และบรรทัดรองบอก
  ขั้นตอนที่ต้องทำกับผู้ส่ง (ชื่อและส่วนงาน) ดูได้ทันทีว่าเป็นหนังสืออะไร มาจากใคร
- เมื่อหนังสือเสร็จสิ้น ผู้จัดทำจะได้รับแจ้งพร้อมชื่อเรื่อง
- To-do ที่ได้รับก่อนวันที่อัปเดตยังแสดงแบบเดิม

### ปรับปรุง — ดูตัวอย่างเอกสารได้ทุกสถานะ

- ปุ่ม **ดูตัวอย่างเอกสาร** แสดงในทุกสถานะ ไม่ใช่เฉพาะร่าง เช่น
  หนังสือที่ถูกตีกลับดูหน้าตาบันทึกข้อความได้โดยไม่ต้องดาวน์โหลด PDF

### ปรับปรุง — เลือกส่วนงานและตำแหน่งจากแผนผังองค์กร

- ช่องเลือกส่วนงานในสารบรรณ (หน่วยงานผู้ส่ง ส่วนงานในเส้นทาง เล่มทะเบียน ฯลฯ)
  แสดงเป็นแผนผังตามโครงสร้างองค์กร เรียงตามรหัสส่วนงาน
- ช่องเลือกตำแหน่งในเส้นทางจัดกลุ่มตามส่วนงาน หาตำแหน่งที่ต้องการได้ง่ายขึ้น

### ใหม่ — ผู้ดูแลระบบแก้เส้นทางของหนังสือที่กำลังเวียนได้

- ผู้ดูแลระบบสารบรรณที่ได้รับสิทธิ์ แก้เส้นทางของหนังสือที่ **กำลังดำเนินการ**
  ได้โดยไม่ต้องดึงกลับ
  - ขั้นที่ยังไม่ถึงคิว แก้ไขหรือลบได้
  - ขั้นที่กำลังรอ เปลี่ยนผู้รับหรือลบได้
  - ขั้นที่ดำเนินการแล้ว แก้ไขไม่ได้
- ผู้ที่ถูกนำออกจากเส้นทางจะไม่เห็นหนังสือนั้นอีก
  และทุกการแก้ไขบันทึกไว้ในประวัติของหนังสือ
- เมื่อผู้ดำรงตำแหน่งเปลี่ยน (เช่น เปลี่ยนคณบดี) ใช้เมนู **ดึงผู้ดำรงตำแหน่งปัจจุบัน**
  เพื่อส่งงานที่ค้างอยู่ให้ผู้ดำรงตำแหน่งคนใหม่
- แก้ **ตำแหน่งที่ลงนาม** ของผู้ลงนามที่เลือกตำแหน่งผิดได้ แม้หนังสือจะเสร็จสิ้นแล้ว
  ชื่อ ลายเซ็น และวันที่ลงนามยังเหมือนเดิม
- ผู้จัดการสารบรรณใช้เมนู **สร้างไฟล์ PDF ใหม่** เพื่อสร้างฉบับลงนามใหม่หลังแก้ข้อมูล

### แก้ไข — เส้นตารางใน PDF สม่ำเสมอ

- หัวบันทึกข้อความ (หน่วยงาน / ที่ / วันที่ / เรื่อง / เรียน) ไม่มีเส้นบางๆ เมื่อเปิด
  PDF ใน Chrome
- ตารางงบประมาณและตารางรายการในแบบขอให้จัดหา (พ.1) ใช้เส้นขนาดเดียวกันทั้งหมด
- หัวแบบฟอร์ม งปม.303 ของใบโอนงบไม่มีเส้นบางๆ เช่นกัน

## 💰 งบประมาณ

### ปรับปรุง — ใบโอนงบแสดงโครงการและแผนจัดซื้อจัดจ้างที่เกี่ยวข้อง

- ใบโอนงบมีแท็บ **โครงการ/กิจกรรม** และ **แผนจัดซื้อจัดจ้าง**
  แสดงรายการที่โอนเข้าหรือออก พร้อมส่วนงาน ทิศทาง และจำนวนเงิน
- กดปุ่ม **เปิด** เพื่อเปิดโครงการหรือแผนนั้นในแท็บใหม่

### ปรับปรุง — ข้อความแจ้งเตือนเมื่อเลือกรหัสงบไม่ถูกระดับชัดเจนขึ้น

- ถ้าโอนออกจากรหัสที่ไม่ได้รับจัดสรรงบโดยตรง ระบบแจ้งว่า
  "โอนออก/ปรับลดงบจากรหัสนี้ไม่ได้ เพราะรหัสนี้ไม่ได้รับจัดสรรงบโดยตรง"
  พร้อมบอกรหัสที่มีงบจัดสรรอยู่ ให้เปลี่ยนไปใช้รหัสนั้น
- ถ้าโอนเข้ารหัสที่ทับซ้อนกับรหัสที่มีงบอยู่แล้ว ระบบแจ้งว่า
  "จัดสรร/โอนงบเข้ารหัสนี้ไม่ได้ เพราะทับซ้อนกับรหัสที่มีงบจัดสรรอยู่แล้ว"
  พร้อมบอกรหัสที่ทับซ้อน

## 📁 โครงการ/กิจกรรม

### ใหม่ — จัดสรรงบประมาณ (งบลอย) จากหน้าโครงการ

- เจ้าหน้าที่งบประมาณกดปุ่ม **จัดสรรงบประมาณ (งบลอย)** บนโครงการได้
  ตั้งแต่ส่งเข้าแผนจนถึงระหว่างดำเนินโครงการ
- ทำตามขั้นตอน: เลือกเงินลอย → ระบุจำนวนเงิน → ตรวจสอบ → **ยืนยันโอน**
  ระบบสร้างใบโอนงบและผ่านรายการทันที ไม่ต้องขออนุมัติผ่านสารบรรณ
- ใบโอนที่สร้างจากหน้าโครงการค้นหาได้ด้วยตัวกรอง **จัดสรรตรงจากงบลอย** ในรายการใบโอนงบ
- ถ้าโครงการเริ่มใช้จ่ายแล้ว เงินที่จัดสรรเพิ่มจะเข้าโครงการ
  แต่ใบจองงบเดิมจะไม่เพิ่มตามอัตโนมัติ (ระบบแจ้งเตือนก่อนยืนยัน)

### ปรับปรุง — แบบเสนอโครงการ (PDF) จัดหน้าเรียบร้อยขึ้น

- หัวข้อไม่ค้างอยู่ท้ายหน้าโดยแยกจากเนื้อหา แถวตารางไม่ถูกตัดข้ามหน้า
  และหัวตารางแสดงซ้ำทุกหน้า
- ข้อความยาวจัดชิดขอบซ้ายขวาแบบเอกสารภาษาไทย
- รหัสโครงการแสดงที่มุมขวาบนเมื่อออกรหัสแล้ว
- ช่อง **หลักการและเหตุผล** จัดรูปแบบข้อความได้ และกด Tab เพื่อย่อหน้าได้
  ข้อความเดิมยังอยู่ครบพร้อมการขึ้นบรรทัดใหม่
- การแก้ไขช่อง **หลักการและเหตุผล** จะไม่บันทึกในประวัติการเปลี่ยนแปลงของโครงการอีก

## 🛒 แผนจัดซื้อจัดจ้าง

### ใหม่ — แนบเอกสารในแผนจัดซื้อจัดจ้าง

- แผนจัดซื้อจัดจ้างมีส่วน **เอกสารแนบ** สำหรับแนบเอกสารประกอบ แนบเพิ่มได้จนกว่าแผนจะ
  **จัดซื้อจัดจ้างเสร็จสิ้น** หรือถูก **ยกเลิก**

### ปรับปรุง — หน้าเผยแพร่แผนจัดซื้อจัดจ้างแบบใหม่

- หน้าเผยแพร่แผนจัดซื้อจัดจ้างประจำปี (ภาพรวม รายส่วนงาน และรายแผน) ออกแบบใหม่
  มีสรุปจำนวนแผนและวงเงิน สัดส่วนแหล่งเงิน ความคืบหน้าการดำเนินงาน และเลือกปีงบประมาณได้
- หน้ารายส่วนงานค้นหา กรองตามสถานะ และแบ่งหน้าได้
- ยอดรวมถูกต้องขึ้น: ไม่รวมแผนที่ยกเลิก
  และยอดงบประมาณแผ่นดินกับเงินรายได้รวมกันได้เท่ากับวงเงินรวม
- วันที่แสดงเป็น พ.ศ. และหมายเหตุของแผนแสดงเฉพาะผู้ใช้ภายใน
