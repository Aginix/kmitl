# มีอะไรใหม่ — 28 ตุลาคม 2569

## 💰 งบประมาณ

### ปรับปรุง — ใบจองงบประมาณ: ลบ กลับแบบร่าง และส่งคืนเงินเหลือจ่ายแบบใหม่

- ปุ่ม **กลับแบบร่าง** ใช้ได้กับใบจองที่ **จองงบประมาณ**
  แล้วแต่ยังไม่มีการเบิกจ่ายหรือใช้ยอดเงิน ระบบจะคืนยอดที่จองไว้และคงเลขที่ใบจองเดิม
- ลบใบจองได้เมื่อเป็น **แบบร่าง** หรือยกเลิกแล้วเท่านั้น
  ใบจองที่เคยมีความเคลื่อนไหวในบัญชีงบประมาณ จะถูกซ่อนไว้ (ดูได้ที่ตัวกรอง **ถูกลบ**)
  และนำกลับมาได้ด้วย **กลับแบบร่าง**
- ระบบจะไม่อนุญาตให้กลับแบบร่างหรือลบ หากมีเอกสารที่ยังอ้างถึงใบจองนั้นอยู่ (เช่น
  ใบขอเบิก ใบขออนุมัติ) โดยจะแจ้งรายชื่อเอกสารให้ทราบ
- หน้าจอ **ส่งคืนเงินเหลือจ่าย** ออกแบบใหม่เป็น 2 ขั้น:
  ตรวจสอบรายละเอียดและยอดก่อนยืนยัน แล้วแสดงใบสรุปการคืนเมื่อสำเร็จ
- ช่อง "วงเงินอนุมัติ" ในใบจองเปลี่ยนชื่อเป็น **ยอดจองงบประมาณ**
  และหน้าใบจองจัดหน้าใหม่ให้อ่านง่ายขึ้น

### ปรับปรุง — คำขอรับการสนับสนุนงบประมาณ

- เพิ่มช่อง **ชื่อเรื่อง** (ต้องกรอกก่อนส่งคำขอ)
  และใช้เป็นเรื่องของหนังสือที่ออกจากระบบสารบรรณ
- ช่อง **วันที่ส่งคำขอ** ระบบบันทึกให้อัตโนมัติเมื่อผู้ขอกดยืนยัน (ไม่ต้องกรอกเอง)
- ระหว่างที่คำขออยู่ในขั้น **ตรวจสอบ** ผู้ตรวจ (Buddy) แก้ไขคำขอได้เลยโดยไม่ต้องส่งกลับ
- แทนที่การ **ยกเลิก** ด้วยการ **ลบ** — ลบได้เมื่อคำขอกลับเป็นแบบร่างแล้ว
  และยังไม่มีใบโอนหรือใบจองอ้างถึง (กรณีใช้สารบรรณ ต้องไม่มีหนังสือที่ยังใช้งานอยู่)
- เลือก **รหัสงบประมาณ** ในคำขอได้
  และรหัสนี้จะถูกเติมลงในใบโอน/ใบจองที่ส่วนกลางดำเนินการต่อ (ส่วนกลางแก้ไขได้)
- ใหม่ — ปุ่ม **ดูตัวอย่างเอกสาร** แสดงตัวอย่างหนังสือจากคำขอแบบร่างก่อนสร้างหนังสือจริง
  (มีลายน้ำ "ตัวอย่าง")

## 💸 เบิกจ่าย

### ใหม่ — มอบหมายผู้รับผิดชอบภายในสถานี

สถานีสามารถตั้ง **กฎการมอบหมาย** ให้ระบบเลือกผู้รับผิดชอบใบขอเบิกหนึ่งคนเมื่อใบเข้าสถานี
เฉพาะผู้ได้รับมอบหมายเท่านั้นที่ดำเนินการและส่งต่อได้ ส่วนเจ้าหน้าที่คนอื่นของสถานีกด
**มอบให้ฉัน** เพื่อรับงานแทน (เช่น กรณีลา) และผู้ดูแลสถานีกด **มอบหมาย…** ให้ใครก็ได้
ทุกครั้งที่เปลี่ยนมือจะมีบันทึกในประวัติ สถานีที่ไม่ได้ตั้งกฎจะทำงานเหมือนเดิม

### ปรับปรุง — แถบสถานีหน้าใบขอเบิก

ใต้หัวใบขอเบิกมี **แถบสถานี** แสดงเส้นทางของใบ (สถานีที่ผ่านแล้ว สถานีปัจจุบัน
และสถานีที่เหลือ) ผู้รับผิดชอบ รายการที่ต้องทำ และปุ่ม **ส่งต่อ / เบี่ยงเส้นทาง /
ส่งคืนผู้จัดทำ** ในที่เดียว เห็นเฉพาะเจ้าหน้าที่ของสถานีนั้น

### ใหม่ — ผอ.กองคลัง "เห็นชอบ" ใบขอเบิก

ผอ.กองคลังไม่มีอำนาจอนุมัติ จึงใช้ปุ่ม **เห็นชอบ** แทน **อนุมัติ** (ติดตั้งแทน
การอนุมัติ ผอ.กองคลังแบบเดิม)

### ปรับปรุง — เลขที่ใบขอเบิกอยู่ในตัวเอกสาร

ใน PDF ใบขอเบิก เลขที่ใบขอเบิกย้ายจากมุมหัวกระดาษมาแสดงในเนื้อเอกสาร
ส่วนสถานะที่เคยแสดงว่า "อยู่ระหว่างดำเนินการ" เปลี่ยนเป็น
**อยู่ระหว่างการดำเนินการเบิกจ่าย**
