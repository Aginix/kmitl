# มีอะไรใหม่ — 19 ตุลาคม 2569

## 💰 งบประมาณ

### ใหม่ — ใบจองงบประมาณมีบัญชีงบประมาณของตัวเอง

- ใบจองงบประมาณมีหน้า **บัญชีงบประมาณ** แสดงทุกรายการที่เกิดกับใบจองนั้น ทั้ง จองงบ
  ผูกพัน ตัดงบ และส่งคืนเงินเหลือจ่าย ตรวจย้อนได้ว่ายอดแต่ละส่วนมาจากเอกสารใด
- ใบจองที่มีอยู่เดิมถูกบันทึกย้อนหลังเข้าบัญชีงบประมาณครบแล้ว ยอดจอง ผูกพัน ตัดงบ
  และรายงานงบประมาณยังเท่าเดิม
- หน้า **บัญชีงบประมาณ** และปุ่มดูรายการบันทึกสมุดบัญชีงบประมาณ
  เห็นเฉพาะผู้มีสิทธิ์ดูงบประมาณ

### แก้ไข — โอนงบเข้าโครงการที่เริ่มเบิกจ่ายแล้ว ยอดจองเพิ่มตาม

- เมื่อโอนงบ (รวมถึง **จัดสรรงบประมาณ (งบลอย)**) เข้าโครงการหรือแผนจัดซื้อจัดจ้าง
  ที่จองงบไว้แล้ว ยอดจองของใบจองจะเพิ่มขึ้นทันทีเมื่อใบโอนงบอนุมัติ
  แม้โครงการจะเริ่มเบิกจ่ายไปแล้วก็ตาม เงินที่โอนเข้ามาไม่ค้างอยู่นอกใบจอง
- โอนงบออกจากรหัสงบที่จองไว้ ยอดจองจะลดลงตามในใบโอนงบเดียวกัน
- ระบบจะไม่อนุญาตให้โอนงบออกจากใบจองเกินยอดที่ยังไม่ผูกพัน
  แม้จะแบ่งเป็นหลายบรรทัดในใบโอนงบเดียวกัน

### แก้ไข — เปิดใบจองงบประมาณจากใบขอซื้อและคำขออนุมัติได้

- ผู้ใช้ที่ทำแบบขอให้จัดหา (พ.1) หรือคำขออนุมัติ
  เปิดดูใบจองงบประมาณที่เกี่ยวข้องได้โดยไม่ขึ้นข้อผิดพลาดเรื่องสิทธิ์
- **ทำสำเนา** ใบจองงบประมาณจะได้ฉบับร่างใหม่ที่ไม่มีรายการติดมา
  และการยกเลิกฉบับสำเนาไม่กระทบใบจองต้นฉบับ

### ปรับปรุง — ตัดงบโดยไม่ผ่านใบจองทำได้เฉพาะผู้จัดการงบประมาณ

- การบันทึกตัดงบในสมุดบัญชีงบประมาณโดยตรง (ไม่ผ่านใบจอง) ทำได้เฉพาะ
  **ผู้จัดการงบประมาณ** และต้องระบุ ส่วนงาน แหล่งเงิน กองทุน และกิจกรรม ครบ
  ยอดต้องไม่เกินงบคงเหลือ
- รายการจองงบและผูกพันเกิดจากใบจองเท่านั้น บันทึกเองในสมุดบัญชีงบประมาณไม่ได้

### ใหม่ — Buddy ตรวจสอบใบโอนงบก่อนส่งอนุมัติ

- ผู้จัดการงบประมาณกำหนด **เจ้าหน้าที่ Buddy (ส่วนกลาง)** ให้ดูแลแต่ละส่วนงานได้ที่ เมนู
  **Buddy ดูแลหน่วยงาน** ถ้ากำหนดที่ส่วนงานแม่ จะดูแลส่วนงานย่อยด้วย
- เมื่อผู้ขอกด **ยืนยัน** ใบโอนงบ ใบโอนงบจะอยู่สถานะ **รอตรวจสอบ** และ Buddy
  ที่ดูแลส่วนงานจะได้รับรายการใน To-do
  - Buddy กด **ยืนยันตรวจสอบ** เพื่อส่งต่อไปอนุมัติ หรือ **ส่งกลับแก้ไข**
    พร้อมเหตุผลให้ผู้ขอแก้
  - ระหว่างรอตรวจสอบ เฉพาะ Buddy ที่ดูแลส่วนงานนั้นแก้ไขใบโอนงบได้
- ช่อง **Buddy ผู้ตรวจสอบ** เลือก Buddy หลักของส่วนงานให้อัตโนมัติ ผู้ขอเปลี่ยนเป็น
  Buddy คนอื่นที่ดูแลส่วนงานเดียวกันได้
- Buddy ใช้ตัวกรอง **รอฉันตรวจสอบ** ดูใบโอนงบที่รอตนเองตรวจ
- ระบบจะไม่อนุญาตให้ยืนยันใบโอนงบของส่วนงานที่ยังไม่มี Buddy
  และผู้ขอตรวจสอบใบโอนงบของตนเองไม่ได้

## 📁 โครงการ/กิจกรรม

### ปรับปรุง — จองงบประมาณเมื่อโครงการได้รับอนุมัติ

- ปุ่ม **จองงบประมาณ** ในขั้นตรวจสอบเปลี่ยนเป็น **ยืนยันงบประมาณ**
  เป็นการยืนยันงบที่ได้รับจัดสรร รหัสงบ และมิติงบของโครงการ ยังไม่จองงบ
- ระบบจองงบประมาณให้เองเมื่อโครงการได้รับอนุมัติ (หนังสือขออนุมัติลงนามครบ
  หรืออนุมัติจากหน้าโครงการ)
- ถ้าจองงบไม่สำเร็จ โครงการยังได้รับอนุมัติและเริ่มดำเนินการได้
  ระบบบันทึกเหตุผลไว้ในประวัติของโครงการ และมีปุ่ม **จองงบประมาณ**
  ให้กดจองใหม่เมื่อแก้ไขแล้ว
- โครงการที่จองงบไปแล้วก่อนวันที่อัปเดตยังใช้ใบจองเดิม ไม่ต้องทำอะไรเพิ่ม

## 📝 ใบขอซื้อขอจ้าง (พ.1) และคำขออนุมัติ

### ใหม่ — ตรวจสอบงบประมาณในหน้าต่างลอยข้างเอกสาร

- ปุ่ม **สถานะงบ** บนแบบขอให้จัดหา (พ.1) และบน **คำขออนุมัติ** (เพิ่มใหม่) เปิดหน้า
  **ตรวจสอบงบประมาณ** ที่กรองตามปีงบประมาณ ประเภทงบ และมิติงบของเอกสารนั้นให้แล้ว
- หน้า **ตรวจสอบงบประมาณ** เปิดเป็นหน้าต่างลอยข้างฟอร์ม ลาก ย่อ ขยาย
  และเปิดได้หลายหน้าต่างพร้อมกัน ระหว่างนั้นยังแก้ไขเอกสารต่อได้
- ปุ่ม **สถานะงบ** เห็นเฉพาะผู้มีสิทธิ์ดูงบประมาณ

## 💸 เบิกจ่ายและยืมเงิน

### ปรับปรุง — ใบขอเบิกระบุประเภทผู้รับเงิน ผู้รับเงินอยู่ที่รายการ

- ใบขอเบิกมีช่อง **ประเภทผู้รับเงิน** (บังคับกรอก) แทนช่องผู้รับเงินที่หัวเอกสาร
  ผู้รับเงินระบุที่แต่ละรายการ และเลือกได้เฉพาะผู้รับเงินประเภทนั้น
- ใบขอเบิกเดิมได้ประเภทผู้รับเงินตามผู้รับเงินส่วนใหญ่ในรายการ
- เมื่อกด **ส่ง** ระบบจะตรวจผู้รับเงิน
  - ระบบจะไม่อนุญาตให้ส่ง ถ้ามีรายการที่ผู้รับเงินไม่ตรงกับประเภทผู้รับเงินของใบขอเบิก
  - ระบบเตือนถ้าผู้รับเงินยังไม่มีบัญชีธนาคาร (ผู้มีสิทธิ์ข้ามได้ เช่น จ่ายเงินสด)
- รายการใบขอเบิกค้นหาด้วยชื่อผู้รับเงิน และกรองตามประเภทผู้รับเงินได้
- เลือก **ปีงบประมาณ** ของใบขอเบิกได้เอง (ค่าเริ่มต้นตามวันที่เอกสาร)
  และเลขที่ใบขอเบิกใช้ปีงบประมาณที่เลือก
- ใบขอเบิกแสดงเอกสารต้นทาง (คำสั่งซื้อ รายงานขอซื้อขอจ้าง หรือคำขออนุมัติ)
  เป็นช่องของตัวเอง แทนช่องอ้างอิงเดิม
- คำขออนุมัติที่จ่ายให้ผู้รับเงินหลายประเภท จะได้ใบขอเบิกแยกตามประเภทผู้รับเงิน

## 📨 สารบรรณ

### ปรับปรุง — หน้าต่างดำเนินการแสดงขั้นตอนและวันที่ลงนาม

- หน้าต่างดำเนินการกับหนังสือแสดงขั้นตอนที่กำลังทำ (เช่น เห็นชอบ ลงนาม) และ
  **วันที่ลงนาม** (วันนี้ แบบวันที่ไทย เช่น 18 ตุลาคม 2569)
- ช่องความเห็นเปลี่ยนชื่อเป็น **ความเห็นในการลงนาม**
  ความเห็นที่บันทึกในเส้นทางแล้วแก้ไขภายหลังไม่ได้
- ข้อความความเห็นสำเร็จรูปเลือกจากรายการแบบเลื่อนลง หรือพิมพ์ความเห็นเองได้

- ในบันทึกข้อความ (PDF) ความเห็นของผู้ลงนามแสดงเหนือลายเซ็น
  และลายเซ็นแต่ละคนไม่ถูกแยกข้ามหน้า
