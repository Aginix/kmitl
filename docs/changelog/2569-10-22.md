# มีอะไรใหม่ — 22 ตุลาคม 2569

## 📝 ใบขอซื้อขอจ้าง (พ.1) และคำขออนุมัติ

### ใหม่ — ระบุผู้ยืนยันตรวจสอบในแบบขอให้จัดหา (พ.1)

- ผู้ขอเลือก **ผู้ยืนยันตรวจสอบ** (ธุรการที่จะตรวจใบนี้) ได้ที่ช่องข้างผู้ขอ
  รายชื่อที่เลือกได้คือผู้มีสิทธิ์ตรวจสอบในหน่วยงานเดียวกับใบ
- **ต้องระบุผู้ยืนยันตรวจสอบก่อนส่งคำขอ** ถ้าไม่ระบุ ระบบจะแจ้ง
  "กรุณาระบุผู้ยืนยันตรวจสอบก่อนส่งคำขอ"
- เมื่อส่งคำขอ ผู้ยืนยันตรวจสอบจะได้รับงาน **"ยืนยันตรวจสอบ แบบขอให้จัดหา (พ.1)"**
  ในรายการงานของตนเอง เปลี่ยนตัวผู้ยืนยันระหว่างรอตรวจได้ งานจะย้ายไปที่คนใหม่
- ผู้มีสิทธิ์ตรวจสอบคนอื่นยังกด **ตรวจสอบ** หรือ **ตีกลับ** แทนได้เหมือนเดิม
- ถ้าใบถูกตีกลับมาเป็นร่าง ผู้ขอและผู้สร้างใบจะได้รับงาน **"แก้ไขแบบขอให้จัดหา (พ.1)
  ที่ถูกตีกลับ"** พร้อมเหตุผลที่ตีกลับ
- ค้นหาใบที่รอตัวเองตรวจได้จากตัวกรอง **รอฉันยืนยันตรวจสอบ**
- ช่อง **เจ้าหน้าที่ผู้รับผิดชอบ** เดิมในแบบขอให้จัดหาถูกนำออก

### ใหม่ — ระบุผู้ยืนยันงบประมาณในแบบขอให้จัดหา (พ.1)

- ระบุ **ผู้ยืนยันงบประมาณ** (ผู้จองงบประมาณที่จะดูแลใบนี้) ได้ตั้งแต่ตอนเป็นร่าง
- ธุรการ **ต้องระบุผู้ยืนยันงบประมาณก่อนกดตรวจสอบ** ถ้าไม่ระบุ ระบบจะแจ้ง
  "กรุณาระบุผู้ยืนยันงบประมาณก่อนกดตรวจสอบ"
- งานจองงบประมาณจะส่งถึง **ผู้ยืนยันงบประมาณที่ระบุไว้คนเดียว**
  ไม่ส่งถึงผู้จองงบประมาณทุกคนในหน่วยงานแบบเดิมอีกแล้ว
- ผู้จองงบประมาณคนอื่นยังกดจองงบหรือตีกลับแทนได้
- ค้นหาใบที่รอตัวเองได้จากตัวกรอง **รอฉันยืนยันงบประมาณ**

### ใหม่ — เจ้าหน้าที่ผู้รับผิดชอบคำขออนุมัติ (พจ.1) จาก Buddy พัสดุ

- คำขออนุมัติ (พจ.1) มีช่อง **เจ้าหน้าที่ผู้รับผิดชอบ**
  ระบบเลือกให้อัตโนมัติจากการตั้งค่า **Buddy ดูแลหน่วยงาน** ตามหน่วยงานผู้ขอ
  และเปลี่ยนเองได้ระหว่างที่ใบยังแก้ไขได้
- เจ้าหน้าที่ผู้รับผิดชอบจะได้รับงาน **"จัดทำรายงานขอซื้อ/จ้าง (พจ.1)"** แทน
  เจ้าหน้าที่พัสดุหน่วยงานทุกคน ใบที่ไม่มีเจ้าหน้าที่ผู้รับผิดชอบยังส่งงานแบบเดิม
- ดูใบของตัวเองได้จากตัวกรอง **ที่ฉันรับผิดชอบ**
  และจัดกลุ่มตามเจ้าหน้าที่ผู้รับผิดชอบได้
- ตั้งค่า Buddy ได้ที่เมนู **จัดซื้อ > การกำหนดค่า > Buddy ดูแลหน่วยงาน**

### ปรับปรุง — ช่องผู้ขายแสดงเฉพาะการจ่ายตรง

- ในคำขออนุมัติ (พจ.1) ช่อง **ผู้ขาย** แสดงเฉพาะเมื่อวิธีจ่ายเป็นจ่ายตรงผู้ขาย
  แบบยืมเงินทดรองหรือจ่ายล่วงหน้าจะไม่เห็นช่องนี้

### ปรับปรุง — แจ้งเตือนก่อนส่งสารบรรณเมื่อยังไม่ระบุผู้ขาย

- กด **ส่งเข้าสารบรรณ** โดยยังไม่ระบุผู้ขาย
  ระบบจะแสดงหน้าต่างแจ้งรายการที่ต้องแก้ก่อนส่ง (ยกเว้นแบบยืมเงินทดรองและจ่ายล่วงหน้า)

### แก้ไข — ผู้ใช้ทั่วไปเปิดคำขออนุมัติที่ตั้งเบิกแล้วได้

- ผู้ใช้ทั่วไปเปิดคำขออนุมัติ (พจ.1) ได้ตามปกติ ไม่ติดปัญหาสิทธิ์ ปุ่ม **สร้างใบขอเบิก**
  และปุ่ม **ใบขอเบิก** แสดงเฉพาะเจ้าหน้าที่จัดซื้อ

### แก้ไข — บันทึกใบตรวจรับก่อนแนบไฟล์

- ใบตรวจรับที่สร้างใหม่ต้องกด **บันทึก** ก่อนจึงจะแนบไฟล์ได้ ระบบจะแสดงข้อความ
  "กรุณาบันทึกใบตรวจรับก่อน จึงจะแนบไฟล์ได้" กันไฟล์หาย

### แก้ไข — เส้นตารางในเอกสารคำขออนุมัติเท่ากัน

- PDF คำขออนุมัติแสดงเส้นขอบตารางหนาเท่ากันทุกเส้น และช่องรายละเอียดที่ว่างจะแสดงเป็น
  "-"
