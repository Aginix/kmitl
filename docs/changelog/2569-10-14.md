# มีอะไรใหม่ — 14 ตุลาคม 2569

## 💰 งบประมาณ

### ใหม่ — ดูได้ว่าเงินในแต่ละรหัสงบเป็นของโครงการหรือแผนไหน

- รายงาน **ตรวจสอบงบประมาณ** แสดงรายชื่อ **โครงการ/กิจกรรม** และ **แผนจัดซื้อจัดจ้าง**
  ใต้รหัสงบที่ถือเงินอยู่ พร้อมยอดของแต่ละรายการ
- ยอดที่ยังไม่ได้ระบุโครงการหรือแผนจะแสดงในแถว "ไม่ระบุโครงการ/แผน"
- เปิด/ปิดการแสดงรายการได้ด้วย checkbox และคลิกชื่อเพื่อเปิดดูเอกสารได้ทันที
- เพิ่มปุ่ม **รีเฟรช** สำหรับโหลดข้อมูลรายงานใหม่

### ปรับปรุง — จองงบที่รหัสย่อยได้

- เมื่อจัดสรรงบไว้ที่รหัสระดับบน สามารถจองงบที่รหัสระดับย่อยลงไปได้ เช่น
  จัดสรรที่กิจกรรมหลัก แล้วจองที่กิจกรรมรอง
- หน้าเลือกงบตอนจองแสดง **งบที่จองได้** และระบุว่าคุมงบอยู่ที่รหัสใด
- การคำนวณงบคงเหลือแม่นยำขึ้น ป้องกันการจองเกินงบที่ได้รับจัดสรร
  และนับรวมการจองจากทุกส่วนงานที่ใช้งบก้อนเดียวกัน
- ระบบจะไม่อนุญาตให้จัดสรรหรือโอนงบซ้อนกันระหว่างรหัสระดับบนกับรหัสระดับย่อย
  เพื่อไม่ให้งบถูกนับซ้ำ

### แก้ไข — ใบโอนงบ: ตัวเลือกโครงการ/แผนตรงตามปีงบประมาณ

- ตอนเพิ่มรายการในใบโอนงบ
  ช่องเลือกโครงการหรือแผนจะแสดงเฉพาะรายการในปีงบประมาณเดียวกับใบโอน

## 📁 โครงการ/กิจกรรม

### ปรับปรุง — ติดตามการเคลื่อนไหวงบของโครงการได้เอง

- ปุ่ม **"การเคลื่อนไหวงบ"** บนโครงการแสดงทุกรายการที่เกิดกับงบของโครงการ ได้แก่ จัดสรร
  รับโอนเข้า โอนออก บันทึกงบประมาณ และตัดงบ
- แต่ละรายการบอกสถานะ (ผ่านแล้ว / อยู่ระหว่างดำเนินการ ฯลฯ)
  และบอกว่าเงินโอนมาจากส่วนงานใด
- หัวหน้าโครงการ ผู้ประสานงาน และผู้สร้างโครงการดูได้ทุกคน
  แม้อยู่ต่างส่วนงานและไม่มีสิทธิ์ในระบบงบประมาณ

### แก้ไข — ตารางงบประมาณโครงการแสดงครบทุกประเภทงบ

- ตารางงบประมาณแสดงทุกหมวดประเภทงบตั้งแต่เริ่ม แม้ยังไม่มีรายการ
  เพิ่มรายการใต้หมวดไหนก็ได้ทันที

## 🛒 แผนจัดซื้อจัดจ้าง

### ปรับปรุง — ลบแผนที่ยกเลิกแล้วได้

- ผู้ใช้ลบแผนจัดซื้อจัดจ้างที่ **ยกเลิกแล้ว** ได้เอง (ต้องยกเลิกแผนก่อนจึงจะลบได้)

## 📝 ใบขอซื้อขอจ้าง (พ.1) และคำขออนุมัติ

### ใหม่ — แสดงผู้มีสิทธิ์ดำเนินการในขั้นปัจจุบัน

- เอกสารที่รอตรวจสอบหรือรอยืนยันงบประมาณ จะแสดงรายชื่อผู้ที่มีสิทธิ์ดำเนินการในขั้นนั้น
  ทำให้รู้ว่าเอกสารรอใครอยู่
