Overview
========

The Procurement Plan module allows organizations to:

* Create and manage annual procurement plans
* Track procurement timeline from request to acceptance
* Manage payment schedules and installments
* Integrate with budget commitments and financial dimensions
* Monitor procurement progress with dashboard analytics

Features
========

Procurement Planning
--------------------

* Create procurement plans with detailed specifications
* Define procurement methods and timelines
* Track quantities, units of measure, and total prices
* Link to fiscal years for proper budget period tracking

Financial Dimension Integration
--------------------------------

The module fully integrates with KMITL's 4-dimensional financial framework:

* **Activities (กิจกรรม)**: Government programs and activities
* **Departments (หน่วยงาน)**: Organizational units
* **Funds (กองทุน)**: Fund sources
* **Sources (แหล่งเงิน)**: Money sources

Budget Integration
------------------

* Connect to budget accounts for financial control
* Automatic creation of analytic accounts for tracking
* View related budget commitments directly from procurement plans
* Track budget availability across financial dimensions

Timeline Management
-------------------

Track key milestones in the procurement process:

* Purchase Request (ETA)
* Procurement Announcement (ETA)
* Approval Signing (ETA)
* Contract/Order Signing (ETA)
* Acceptance (ETA)

Payment Scheduling
------------------

* Define multiple payment installments
* Specify payment amounts and disbursement dates
* Track number of days and payment months
* Monitor payment status

Workflow Management
-------------------

Procurement plans follow a defined lifecycle:

* **Draft**: Initial creation and editing
* **New**: Not started yet
* **On Hold**: Temporarily suspended
* **In Progress**: Active procurement
* **Done**: Completed
* **Cancel**: Cancelled

Dashboard & Analytics
---------------------

Interactive dashboard with:

* Total procurement count and amounts
* Status distribution charts
* Department and source filtering
* Fiscal year filtering
* Visual analytics using ECharts

Configuration
=============

Access Rights
-------------

The module provides two security groups:

* **Procurement Plan User**: Can create and edit procurement plans
* **Procurement Plan Manager**: Full access including deletion

Budget users automatically receive procurement plan user access.

Sequence Configuration
----------------------

Procurement plan codes follow the pattern: ``PROP/YYYY/####``

* PROP: Prefix for procurement plans
* YYYY: Buddhist Era year
* ####: 4-digit sequence number

Budget Account Setup
--------------------

To enable procurement planning for budget accounts:

1. Go to Budget > Configuration > Budget Accounts
2. Edit the desired account
3. Enable "ทำแผนจัดซื้อจัดจ้าง" (Procurement Plan) checkbox

By default, accounts under code 53100 (capital investment) are enabled.

Usage
=====

Creating a Procurement Plan
----------------------------

1. Navigate to Procurement Plan > Procurement Plans
2. Click Create
3. Fill in required information:

   * Description (ชื่อรายการ)
   * Fiscal Year
   * Amount and Unit
   * Total Price
   * Financial Dimensions (Activity, Source, Department, Fund)
   * Budget Account

4. Optionally add:

   * Procurement Method
   * Timeline milestones (ETAs)
   * Payment schedule
   * Notes

5. Change state from Draft to appropriate status

Linking to Budget Commitments
------------------------------

When creating budget commitments:

1. Select the procurement plan in the commitment form
2. The commitment will automatically link to the plan's analytic account
3. View commitments from the procurement plan using the smart button

Tracking Progress
-----------------

Use the dashboard to:

* Filter by fiscal year, department, or source
* View overall statistics
* Analyze status distribution
* Track total procurement amounts
